# مهارت جستجوی زنده در وب و ادغام نتایج (9Router Web Search)

این مهارت پاسخ‌های هوش مصنوعی را به اطلاعات روز دنیا متصل می‌کند تا مدل در مواجهه با خطاهای جدید فریم‌ورک‌ها یا سوالات پیرامون آخرین ابزارها دچار توهم (Hallucination) نشود.

### قابلیت‌های کلیدی:
1. **جستجوی بلادرنگ:** پشتیبانی از منابع معتبر شامل GitHub، StackOverflow و داکیومنت‌های رسمی.
2. **استخراج ارجاعات (Citations):** درج لینک‌های منبع در انتهای پاسخ برای ارزیابی کاربر.
3. **فشرده‌سازی نتایج:** استفاده از تکنولوژی RTK برای فشرده‌سازی خلاصه‌ها و مصرف بهینه توکن.
