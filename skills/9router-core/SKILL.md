# درگاه جامع و ارکستراتور هوشمند مدل‌ها (9Router Core Gateway)

این مهارت به عنوان مغز متفکر هدایت درخواست‌ها در OmniOps عمل کرده و از هدررفت بودجه، اتمام سهمیه اکانت‌ها و قطعی در میانه کدنویسی جلوگیری می‌نماید.

### ارکان اصلی:
1. **فشرده‌ساز RTK (کاهش ۲۰٪ تا ۴۰٪ توکن‌های خروجی ابزارها):** پاکسازی خروجی git diff، grep، لاگ‌های بیلد و لیست فایل‌ها قبل از ارسال به مدل.
2. **آبشار ۳ لایه سهمیه‌ها:**
   - لایه ۱: اشتراک‌ها (Claude Code، OpenAI Codex، GitHub Copilot)
   - لایه ۲: مدل‌های ارزان‌قیمت (GLM-5، MiniMax)
   - لایه ۳: مدل‌های رایگان نامحدود (Kiro AI، OpenCode Free، اعتبار Vertex) + مدل‌های محلی
3. **درگاه جهانی OpenAI Compatible:** ارائه اندپوینت استاندارد `/v1/chat/completions` برای اتصال ابزارهایی مانند Cursor، Cline، Claude CLI و Windsurf.
