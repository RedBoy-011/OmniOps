# مهارت استخراج و پالایش محتوای وب (9Router Web Fetch)

این مهارت آدرس‌های اینترنتی را خوانده و کدهای HTML، تگ‌های تبلیغاتی و استایل‌های اضافه را پاکسازی نموده و متن خالص و ساختارمند در اختیار مدل هوش مصنوعی می‌گذارد.

### قابلیت‌های کلیدی:
1. **پاکسازی کدهای زائد:** حذف تگ‌های اسکریپت، استایل و بنرهای تبلیغاتی برای جلوگیری از سوختن توکن.
2. **تبدیل به Markdown استاندارد:** جداول، لینک‌ها و عناوین به شکل تمیز ساختاردهی می‌شوند.
3. **پشتیبانی از پروکسی و شبکه محلی:** امکان عبور از فیلترینگ یا اتصال به اینترانت شرکتی.
