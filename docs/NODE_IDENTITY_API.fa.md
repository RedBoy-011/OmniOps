# هویت گره‌های Worker و Edge (بخش آمادهٔ آزمون)

تا ۲ اکتبر ۲۰۲۶، کد هستهٔ صدور مجوز و رجیستری گره نوشته و به API وصل شده است. روی Master داخلیِ فعلی که HTTP دارد، همهٔ مسیرهای این بخش با پاسخ `426` بسته‌اند؛ **هیچ مجوزی را روی HTTP ارسال نکنید**. این مرحله هنوز به نصب‌کنندهٔ سه‌نقشی، پنل گرافیکی یا سرور واقعی متصل نشده و در درصد استقرار منظور نشده است.

## قرارداد API

Master فقط در صورتی مسیرهای زیر را اجرا می‌کند که اتصال ورودی **مستقیماً TLS 1.3** باشد؛ مقدار `X-Forwarded-Proto` پذیرفته نمی‌شود. برای TLS مستقیم باید مسیر گواهی و کلید خصوصی معتبر در `OMNIOPS_TLS_CERT` و `OMNIOPS_TLS_KEY` تنظیم شوند. هر دو میزبان باید اعتبار گواهی و نام Master را مستقل بررسی کنند؛ از `curl -k` یا نادیده‌گرفتن خطای گواهی استفاده نمی‌شود. قرار دادن Caddy بدون TLS بین آن و Master باعث فعال‌شدن این API نمی‌شود؛ TLS سرتاسری یا تونل با TLS داخلیِ معتبر لازم است.

- `POST /api/admin/nodes/grants` با Bearer نشست SuperAdmin و بدنهٔ `{"role":"worker"}` یا `edge`: خروجی `id`، `grant` و `expires_at`. مجوز ۲۵۶ بیت تصادفی است، ۱۰ دقیقه اعتبار دارد، فقط هش کلیددارش ذخیره می‌شود و یک بار مصرف می‌شود. نمایش آن فقط در پاسخ صدور است.
- `POST /api/admin/nodes/grants/revoke` با `{"id":"..."}`: ابطال مجوز مصرف‌نشده.
- `POST /api/nodes/enroll` با `{"grant":"...","name":"worker-01"}`: خروجی `id`، `role`، `credential` و `credential_expires_at`. نقش گره فقط از مجوز صادرشده خوانده می‌شود. اعتبارنامه ۳۰ روزه است و فقط هش کلیددارش در Master می‌ماند؛ گره باید مقدار دریافتی را فقط روی همان میزبان با دسترسی فایل `0600` نگه دارد.
- `POST /api/nodes/heartbeat` با `{"id":"...","credential":"...","metrics":{"version":"1.0","cpu_percent":12,"ram_percent":45,"disk_percent":56,"models":["qwen3:0.6b"]}}`: آخرین حضور را ثبت می‌کند؛ داده‌های اختیاری محدود و راستی‌آزمایی می‌شوند.
- `POST /api/nodes/rotate` با `{"id":"...","credential":"..."}`: اعتبارنامهٔ قدیم را به‌صورت اتمیک با مقدار جدید جایگزین می‌کند.
- `POST /api/admin/nodes/revoke` با `{"id":"..."}`: گره را غیرفعال می‌کند و اعتبارنامهٔ آن بلافاصله رد می‌شود.
- `GET /api/admin/nodes`: فهرست گره‌ها، وضعیت ابطال، انقضای اعتبارنامه و آخرین heartbeat، بدون هیچ مقدار محرمانه.

ساخت Worker daemon با دسترسی محدود، آزمون TLS واقعی، نمایش این داده‌ها در پنل، گزارش مرحله‌های نصب و سیاست نگهداری تله‌متری در گام بعدی است. نصب‌کنندهٔ خودکار نباید از این API تا آزمون گواهی معتبر استفاده کند. دروازهٔ پیش از انتشار اینترنتی شامل چرخش رمزهای افشاشده و یکتاسازی کلید میزبان SSH است.
