# Worker محلی Ollama و تشخیص استقرار

این مرحله برای سرور پردازشی داخل شبکهٔ خصوصی است. Master و Worker باید نشانی خصوصی جدا داشته باشند. این نسخه نصب از پنل یا کنترل دستورات root از راه دور ندارد؛ اسکریپت زیر روی خود Worker و با حساب مدیر اجرا می‌شود. برای مدل‌های سنگین، وجود GPU، درایور و فضای دیسک کافی را جداگانه بررسی کنید.

## نصب تکرارپذیر

از پوشهٔ مخزن تازهٔ OmniOps روی Worker:

```bash
bash scripts/install-ollama-worker.sh --bind-ip WORKER_PRIVATE_IP
```

اسکریپت انتشار رسمی نسخهٔ pin شده را از GitHub می‌گیرد، checksum اعلام‌شدهٔ همان انتشار را بررسی می‌کند، کاربر سرویس بدون دسترسی root می‌سازد، API را فقط روی IP خصوصی Worker گوش می‌دهد و `/api/tags` را آزمایش می‌کند. اگر فایل رسمی قبلاً دریافت شده باشد، همان فایل را می‌توان بدون دانلود دوباره داد؛ اعتبار checksum همچنان بررسی می‌شود:

```bash
bash scripts/install-ollama-worker.sh --bind-ip WORKER_PRIVATE_IP --archive /path/to/ollama-linux-amd64.tar.zst
```

در محیط آزمون می‌توان یک مدل سبک دریافت کرد:

```bash
ollama pull qwen3:0.6b
curl --noproxy '*' -fsS http://WORKER_PRIVATE_IP:11434/api/tags
```

برای اتصال از پنل مدیرکل Master، نشانی `http://WORKER_PRIVATE_IP:11434` را در «اتصال Worker مدل» وارد و «تست و ذخیره» را بزنید. فقط پس از موفقیت، فهرست مدل و چت ایجنت از آن Worker استفاده می‌کنند. در صورت قطع Worker خود Master پاسخ `/health` می‌دهد و چت با خطای واضح متوقف می‌شود.

## عیب‌یابی بدون نمایش کلیدها

روی Master، در پوشهٔ نصب واقعی:

```bash
python3 scripts/diagnose-ubuntu.py
```

این دستور وضعیت سرویس، پاسخ Master، سلامت خواندنی دیتابیس، دسترسی Ollama و نام مدل‌ها را به‌شکل JSON نشان می‌دهد. رمز عبور، کلید API و کلید امضا را چاپ نمی‌کند. کد خروج صفر یعنی همهٔ بخش‌ها در دسترس‌اند؛ کد ۲ یعنی دست‌کم یک جزء نیاز به بررسی دارد. ابتدا `systemctl status omniops-master.service` یا `systemctl status ollama.service` و سپس لاگ مرتبط را بررسی کنید.

پورت ۱۱۴۳۴ را به اینترنت عمومی منتشر نکنید. اتصال اولیه روی LAN خصوصی است؛ محدودسازی فایروال و تونل بین گره‌ها پیش از استقرار عمومی Edge تکمیل می‌شود. به‌روزکردن Master با دستور [راهنمای به‌روزرسانی](ONE_LINE_UPDATE.fa.md) از پایگاه داده و کلیدهای موجود پشتیبان می‌گیرد.
