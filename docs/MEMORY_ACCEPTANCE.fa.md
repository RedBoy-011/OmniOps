# گزارش پذیرش حافظه و نمای گفتگو

زمان ثبت: ۳ اکتبر ۲۰۲۶ به وقت تهران. کد پذیرفته‌شدهٔ این مرحله: `e55c235`.

## آزمون اجراشده

- ۷۸ آزمون Python روی Master بعد از دریافت commit موفق؛ ۴ آزمون طبق شرایط محیطی skipped. build پنل وب روی Master و CI موفق.
- اجرای آزمایش مستقل روی خود Master با گواهی معتبر CA خصوصی و TLS 1.3: پایگاه‌داده و دو حساب آزمایشی جدا در پوشهٔ موقت، ۲۱ درخواست HTTP، کنترل دسترسی مدیر/عضو، مجوز نشست وب در برابر نشست ایجنت، ثبت و حذف حافظهٔ عضو، منع دسترسی مدیر به دادهٔ عضو، جفت‌سازی کوتاه‌عمر و یک پاسخ واقعی مدل محلی Worker. خروجی `PASS`؛ بعد از آزمون پوشهٔ موقت حذف شد. این آزمون حساب‌های عملیاتی را تغییر نداد.
- سرویس واقعی Master در نسخهٔ `e55c235` با `omniops-master.service` روی HTTP خصوصی `9000` و `omniops-master-tls.service` روی HTTPS خصوصی `9443` فعال شد. سلامت هر دو پاسخ `up` داد؛ مسیر حافظه روی HTTPS بدون نشست `401` برگرداند. از گواهی CA معتبر با تطبیق IP استفاده شد و فایروال پورت تازه‌ای باز نشد.
- GitHub Actions اجرای `37062329141` موفق بود: آزمون Python، ساخت وب، `cargo check --locked`، آزمون Rust، ساخت نصب‌کنندهٔ NSIS ویندوز و checksum. فایل نصب دریافت شد، ۳٬۳۳۴٬۴۲۶ بایت و SHA256 آن با فایل همراه مطابقت داشت. بستهٔ ویندوز امضای دیجیتال ندارد و روی دستگاه کاربر نصب/اجرا نشده است.

## دروازهٔ باز

- آزمون تصویری پنل واقعی روی `9443` با حساب مدیر و عضو، مرورگر دارای اعتماد به CA و سناریوی حذف/بازورود انجام نشده است. تغییر trust store مرورگر یا عبور از هشدار گواهی خودکار انجام نمی‌شود.
- ایجنت دارای رابط حافظه و ذخیرهٔ opt-in ساخته شده، اما نصب و تعامل آن با نشست واقعی کاربر روی ویندوز و قطع/اتصال دوباره هنوز مشاهده نشده است.
- افزودن پیوست تصویر/متن از حافظه، حالت گفتگو/وظیفه و پروژه صرفاً در [نقشهٔ فضای کاری](WORKSPACE_PRODUCT_ROADMAP.fa.md) ثبت شده‌اند؛ API پیوست و کار هنوز ساخته نشده است. pilot Khoj هنوز شروع نشده است.
