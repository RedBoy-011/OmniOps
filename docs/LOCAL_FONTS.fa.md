# فونت‌های محلی رابط

رابط وب (ورود، پنل و سایر صفحات) و ایجنت ویندوزی در صورت وجود از IRANSharp با وزن‌های سبک، عادی و ضخیم استفاده می‌کنند. در نبود فایل‌ها فونت جایگزین سیستم نمایش داده می‌شود.

برای آماده‌سازی **محلی** در ویندوز، از ریشهٔ مخزن اجرا کنید:

```powershell
powershell -ExecutionPolicy Bypass -File scripts/install-local-fonts.ps1 -FontDirectory 'C:\Users\arfaghani\Downloads\Compressed\IRANSharp'
```

فایل‌های فونت و `FontLicense.txt` در مسیر `public/fonts/omniops-iransharp/` هر رابط کپی می‌شوند و با `.gitignore` از Git کنار گذاشته شده‌اند. فایل مجوز موجود، فونت را مالکیتی معرفی می‌کند و جای کد مجوز آن خالی است. پیش از ارائهٔ بستهٔ ویندوز یا سرو عمومی فونت از Master، مجوز مناسب و کد آن باید توسط مالک پروژه تعیین شود. استقرار مبتنی بر GitHub این فایل‌ها را همراه ندارد و فونت جایگزین را نشان می‌دهد. در پوشهٔ `dist` محلی ممکن است فونت کپی شده باشد؛ آن را بدون مجوز منتشر نکنید.
