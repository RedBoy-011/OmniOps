# فونت پیش‌فرض OmniOps

وزیرمتن (Vazirmatn) نسخهٔ 33.0.3 فونت پیش‌فرض رابط وب و ایجنت ویندوزی است. فایل متغیر WOFF2 همراه بستهٔ رسمی npm در build قرار می‌گیرد و بدون اتصال به CDN کار می‌کند. مجوز SIL Open Font License 1.1 و نام پدیدآورندگان در [Vazirmatn-OFL.txt](licenses/Vazirmatn-OFL.txt) محفوظ‌اند.

فونت‌های مالکیتی IRANSharp که پیش‌تر برای آزمایش محلی آماده شده‌اند، جزو build و مخزن عمومی نیستند. پوشهٔ محلی آن‌ها همچنان در `.gitignore` می‌ماند تا سهواً منتشر نشود؛ اسکریپت نصب محلی پیشین حذف شده و پوشهٔ `public` مالکیتی هر دو رابط در فرایند build غیرفعال است و فقط `public-open` همراه متن مجوز فونت کپی می‌شود؛ بنابراین نسخه‌های محلی IRANSharp نیز وارد خروجی نمی‌شوند.
